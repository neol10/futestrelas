# Bases de referência dos jogadores

Essas são as bases visuais que vou usar para criar sprites parecidos.

## Bases principais
- `base_brasil` — camisa amarela, detalhes verdes, shorts azuis
- `base_espanha` — camisa vermelha, detalhes amarelos, shorts claros
- `base_italia` — camisa branca, detalhes verde/vermelho, shorts escuros

## Padrão de nome dos arquivos
Quando você salvar as imagens na pasta, pode usar:
- `brasil.png`
- `espanha.png`
- `italia.png`

## Padrão visual
- Sprite-sheet horizontal com 3 frames
- Fundo transparente
- Corpo centralizado
- Movimento simples: idle, passo 1, passo 2

Se quiser, eu também posso criar nomes-base para todos os times do jogo no mesmo padrão.
