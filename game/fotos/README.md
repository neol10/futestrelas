# Fotos dos Jogadores

Coloque aqui os sprites de cada time para o jogo carregar automaticamente.

## Nome dos arquivos
Use o nome do time em minúsculas, sem acentos e com underscore quando necessário:

- `brasil.png`
- `argentina.png`
- `franca.png`
- `alemanha.png`
- `espanha.png`
- `italia.png`
- `inglaterra.png`
- `portugal.png`
- `holanda.png`
- `belgica.png`
- `uruguai.png`
- `mexico.png`
- `japao.png`
- `eua.png`
- `croacia.png`
- `suecia.png`

## Formato esperado
- Sprite-sheet horizontal com 3 quadros de animação.
- Cada quadro com o mesmo tamanho.
- Fundo transparente, se possível.

Se o arquivo não existir, o jogo usa automaticamente o fallback visual atual.
